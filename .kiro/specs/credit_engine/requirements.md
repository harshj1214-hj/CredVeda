# Requirements: Transparent Credit Scoring Engine

- **REQ-1:** System shall ingest user applicant data and compute DTI and Disposable Income.
- **REQ-2:** Model shall classify applicants into Risk Tiers (0, 1, 2) via Random Forest.
- **REQ-3:** System shall explain risk tiers using SHAP feature importances.
- **REQ-4:** System shall provide counterfactual debt-reduction recommendations.
